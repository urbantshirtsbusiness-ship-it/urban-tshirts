URBAN T-SHIRTS — V4

This is a new version based on the V3 bug-fixed website. The original V3 ZIP is not modified or overwritten.

V4 additions:
- Dark/light theme toggle with saved preference
- Working wishlist with saved items/count
- Improved size handling, including combo size updates
- Safer product rendering for names containing quotes/special characters
- Safer localStorage loading when stored data is damaged
- Cart count now counts individual tees (a 3-piece combo counts as 3)
- Better empty states and toast handling
- Escape key closes cart/image preview
- Separate V4 localStorage keys so V3 data is not overwritten
- Admin page updated to V4 storage and dark theme

Deployment: upload this whole folder or its ZIP as a static site. index.html is the storefront entry point.
