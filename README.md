# URBAN T-SHIRTS — Streetwear & Anime Apparel Store

A modern, fast, and responsive static e-commerce storefront with an integrated client-side product management admin portal.

## ✨ Features

- **Storefront & Catalog**: Responsive grid with search and category filtering (Anime, Streetwear, Graphic, etc.).
- **Dynamic 3-Piece Combo Deal**: Interactive ₹499 combo builder with size selection.
- **Cart & Slide-in Bag**: Real-time quantity tracking, item breakdown, and automatic price calculations.
- **WhatsApp Checkout**: Instant order generation sent directly to WhatsApp with full itemized details.
- **Wishlist & Theme Mode**: Dark/Light theme toggle with persistent user preferences in `localStorage`.
- **Integrated Admin Portal (`/admin` or `/admin.html`)**: Add, edit, and delete catalog items in real time.

## 🚀 Deployment to Vercel

1. Import this repository into [Vercel](https://vercel.com).
2. Framework Preset: **Other** (Static HTML/CSS/JS).
3. Root Directory: `./` (leave default).
4. Click **Deploy**.
