How to update the website

  1. Put a new product photo inside the assets folder.
  2. Enter its path, for example assets/new-tee.jpg.
  3. Add the product name, price, category and sizes, then click Save product.
  4. Open index.html to see the updated collection.

Important: This version is a front-end store. The manager saves changes only in the browser/device where you edit it. For a real online shop where you can manage products from any phone, the next step is to connect a database/admin backend.
